# Dispensa 07 — Pareti Multistrato in Serie e Coefficienti Liminari

## Richiami teorici
In serie le resistenze si sommano: $R\text{'}_{\text{tot}} = \frac{1}{\alpha_{\text{in}}} + \sum_i \frac{L_i}{\lambda_i} + \frac{1}{\alpha_{\text{out}}}$.

## Esercizio
Una parete ha intonaco ($L_1 = 2\ \text{cm}$, $\lambda_1 = 0{,}70$), muratura ($L_2 = 30\ \text{cm}$, $\lambda_2 = 0{,}50$) e isolante ($L_3 = 8\ \text{cm}$, $\lambda_3 = 0{,}032$). Con $\alpha_{\text{in}} = 8$, $\alpha_{\text{out}} = 25$, $\Delta T = 20\ \text{K}$, calcolare $R\text{'}_{\text{tot}}$ e $\dot{q}$.

### Svolgimento
- $R\text{'}_{s,i} = 0{,}125$, $R\text{'}_1 = 0{,}0286$, $R\text{'}_2 = 0{,}600$, $R\text{'}_3 = 2{,}500$, $R\text{'}_{s,e} = 0{,}040$
- $R\text{'}_{\text{tot}} = 3{,}294\ \text{m}^2\cdot\text{K/W}$
- $\dot{q} = \frac{20}{3{,}294} \approx 6{,}07\ \text{W/m}^2$
